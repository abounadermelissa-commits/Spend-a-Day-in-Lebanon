# Spend-a-Day-in-Lebanon
<h1>My project Overview</h1>
<h5> So Spend a day in Lebanon is a funny, character based discovery into some of the most known Lebanese cities! Although the cities I put are certainly not enough to show the Lebanese variety and beauty, but it's a good start to not only know some cities, but also discover the mentality of the Lebanese people through the behaviors that the characters do. Enjoy!</h5>
<h2> What I Used:</h2>
<ul>
  <li>HTML (hyper-text-markup-language)</li>
  <li>CSS(Cascading Style Sheets)</li>
  <li>JS (JavaScript)</li>
</ul>
<h2>How to Use it:</h2>
<p>Using this entertaining site is very simple and straightforward. You simply click the button to start with the first city and can click the next button to dive into the next one. At the end, you can click a revisit button that is gong to reload the page to the start.</p>
